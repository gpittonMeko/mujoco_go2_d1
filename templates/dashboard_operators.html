Grasp Teaching · presa autonoma (RealSense metrico)

Non è una chat Hermes. Il percorso principale è ▸ Prendi: Scansione +90° → pyrealsense2 polso → loop IK autonomo. OpenAI interviene solo come supervisor (veto sì/no) nel loop «Prendi», non comanda la traiettoria. Lo step coach GPT (Avanzato) con START laterale è solo metrico — niente chiamata GPT finché non passi a START frontale o disattivi GO2_GRASP_COACH_LATERAL_METRIC_ONLY sulla NX. Coach API: …

Flusso operatore: partenza automatica da Scansione +90° → gate metrici polso → presa autonoma (o raccolta se l’istruzione contiene «raccogli»). Stack braccio = tab Braccio D1 · giunti (coppia persistente, niente kill DDS).

Prendi · un comando modalità: —

Procedura poka-yoke — non saltare step
Camera polso: opzionale, premi se vuoi verificarla
Prossimo step: START +90°
  1. START +90°: porta il polso in posa scansione.
  2. ① Leggi target: acquisisce RGB+depth e mostra dove vede l'oggetto.
  3. ② Muovi al target: test controllato. Se va fuori, non premere Prendi.
  4. ③ Salva presa vera: durante il countdown metti a mano le pinze sulla presa corretta.
  5. Ripeti ①→②→③ in 3 posizioni per oggetto. Poi usa ▸ Prendi.
